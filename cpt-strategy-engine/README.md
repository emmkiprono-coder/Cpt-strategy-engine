# CPT Strategy Engine

Interactive CPT Code Strategy Engine with agentic reasoning and financial foresight for healthcare practitioners and business operators.

## Features

- **Command Center** — Service line overview with revenue projections and risk scores
- **Code Explorer** — Deep-dive CPT analysis with plain-English explanations
- **Scenario Lab** — What-if simulator for telehealth, CCM, RPM, payer mix scenarios
- **Service Line Builder** — Configure and optimize service lines with real-time modeling
- **Compliance Scan** — Audit exposure analysis with documentation requirements
- **Strategy Agent** — Chat interface with agentic reasoning and strategic foresight

## Tech Stack

React 18 + TypeScript + Vite + Tailwind CSS

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Deploy

This project is configured for Vercel deployment. Connect your GitHub repo and Vercel will auto-detect Vite settings.
